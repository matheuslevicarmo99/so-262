# Atividade 03 - Sistemas Operacionais

Este diretório contém a resolução da Atividade 03, que consiste na elaboração de um documento de especificação de projeto para o gerenciador de processos de um simulador de sistema operacional. Esta documentação servirá como entrada para a criação de código gerado a partir de um Harness (Claude Code ou Open Code).
